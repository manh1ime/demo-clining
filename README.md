# Клининговый сайт и приложение продаж

Один шаблон для клининговых компаний: калькулятор, 3D-композиция, форма заявки и Telegram для настоящего клиентского сайта. В том же проекте можно включить CRM `/admin`, добавлять потенциальных клиентов и сразу получать персональные сайты-концепты `/p/<id>` без отдельного деплоя.

### Ваш демонстрационный проект

1. Импортируйте репозиторий в Vercel (Other, без Build Command, Output Directory `.`).
2. Подключите Upstash Redis: `KV_REST_API_URL` + `KV_REST_API_TOKEN`.
3. Добавьте надёжный `ADMIN_PASSWORD`, оставьте `config.js → site.demo: true`, сделайте Redeploy.
4. Откройте `/admin`, добавьте компанию, её контакты, цвет и цены, сохраните.
5. Полученную публичную ссылку приложите к офферу. Кнопки открывают WhatsApp / Telegram / MAX; отправку подтверждаете вы. MAX требует полную проверенную ссылку на чат.

Демо-формы не сохраняют и не отправляют имя/телефон. Счётчик показывает только число тестов. Черновик/копирование/открытие чата не приравниваются к отправке.

### Настоящий сайт клиента

Отдельный Vercel-проект и отдельный Redis. Основные данные и цены — в `config.js`. Заполните реальные реквизиты, домен, sitemap/robots и юридические тексты; настройте Telegram и **только затем** включите `site.demo: false`. `ADMIN_PASSWORD` на клиентском сайте не задавайте. Подробные шаги и ограничения по персональным данным — в полной инструкции.

## Стек

- HTML/CSS/JavaScript, без сборки и runtime-зависимостей npm.
- Three.js через CDN → встроенный native WebGL → статичный fallback.
- Серверные функции Vercel; Redis REST (Upstash); Telegram Bot API.
- Node.js 22+ для локальных тестов и служебных команд.

## Проверки локально

```sh
npm test
npm run dev
```

Локальный стенд: `http://127.0.0.1:4173`, пароль `local-demo-password`. Это **только тестовый стенд с временным Redis и имитацией Telegram**, не production-сервер. `npm run check` проверяет заглушки в настройках и намеренно возвращает ошибку, пока они не заменены.

## Файлы

| Файл | Назначение |
| --- | --- |
| `config.js` | Данные, бренд, цены, демонстрационный/реальный режим |
| `index.html`, `site.js` | Шаблон лендинга, калькулятор и подстановка данных |
| `admin.html`, `api/admin.js` | CRM, поиск по всей базе, постраничная загрузка, CSV, подготовка офферов |
| `api/preview.js` | Публичная конфигурация персонального примера |
| `api/lead.js`, `api/_config.js` | Валидация, серверный пересчёт, тестовые/настоящие заявки |
| `api/_auth.js` | Подписанная HttpOnly-сессия, CSRF-проверки, ограничение входов |
| `api/telegram.js`, `api/_lib.js` | Telegram, Redis, статусы заявок |
| `api/setup.js`, `scripts/setup-telegram.mjs` | Настройка webhook через POST, без секрета в URL |
| `scripts/check-config.mjs` | Проверка готовности настроек |
| `tests/` | Серверные тесты и изолированные doubles внешних сервисов |
| `privacy.html`, `404.html` | Политика и страница ошибки |

Новые отрасли, дополнительные шаблоны, массовая автоматическая рассылка и автоматический выпуск отдельных клиентских Vercel-проектов в этот этап не входят. Один сохранённый лид публикуется как маршрут текущего демонстрационного проекта.
