# Легче: сайт и локальная панель лидов

Проект разделён на две независимые части:

- `index.html` - публичный сайт клининговой компании с калькулятором, 3D-сценой и заявкой в Telegram.
- `leads.html` - внутренняя CRM. Локально открывается без пароля, на Vercel защищена `ADMIN_PASSWORD`.

## Локальная работа

```powershell
npm install
npm run dev
```

Адреса:

- `http://127.0.0.1:5173/index.html` - сайт.
- `http://127.0.0.1:5173/leads.html` - панель лидов.

Перед первым запуском или после обновления исходного JSON можно повторно сформировать локальный модуль данных:

```powershell
npm run import:crm100
```

Исходный JSON не копируется в публичную сборку. Предыдущая база сохранена в резервных копиях и старом ключе браузера, но новая панель её не отображает.

## Создание демо-сайта из CRM

1. Откройте карточку лида и вкладку «Демо».
2. Укажите цвет, текст логотипа, название 3D-комплекта и тарифы.
3. Нажмите «Создать демо-сайт».
4. Проверьте сайт кнопкой «Открыть сайт».
5. Скопируйте ссылку и вставьте её в подготовленное сообщение.

В ссылку попадают только публичные настройки оформления. Телефон, заметки, ID источника и история лида не передаются.

## Сборки

```powershell
npm run build
npm run build:local
```

- `npm run build` создаёт `dist` с публичным сайтом и защищённым экраном CRM. Сама база лидов, контакты и резервные копии туда не попадают.
- `npm run build:local` создаёт `dist-local` для локальной проверки сайта и CRM.

Настройка Telegram и Vercel описана в `DEPLOYMENT.md`. Публикация из этого проекта не выполнялась.

Telegram-бот поддерживает списки заявок, назначение менеджера, заметки и смену статусов через inline-кнопки. Для этих функций подключите Upstash Redis; без Redis обычные уведомления о заявках продолжают работать.
