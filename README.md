# Легче: проект для Vercel

Демонстрационный сайт клининга с 3D, калькулятором и тестовой формой.
Заявки пока не отправляются и не сохраняются. Telegram не подключён.

## Публикация через GitHub

1. Распакуйте архив на компьютере.
2. Создайте пустой репозиторий GitHub, например legche-demo. Можно приватный.
3. Загрузите index.html, vercel.json, README.md и .gitignore в корень репозитория, не в дополнительную папку. ZIP в репозиторий загружать не нужно.
4. В Vercel выберите Add New → Project → импорт этого репозитория.
5. Framework Preset: Other. Root Directory: корень репозитория. Build Command: пустой. Output Directory: точка (.). Зависимости не нужны.
6. Нажмите Deploy. Откройте полученную ссылку .vercel.app.

В vercel.json уже задан статический проект без команды сборки.

## Проверка после публикации

- Открыть сайт на компьютере и телефоне.
- Проверить 3D, кнопку паузы и появление блоков при прокрутке.
- 50 м², поддерживающая уборка: 3500 ₽.
- 80 м², генеральная уборка с окнами: 11600 ₽.
- Короткий телефон должен блокировать форму.
- Корректные тестовые данные должны показывать подтверждение демо без отправки.

## Дальше: Telegram

Следующим изменением добавляем серверный обработчик формы и бота.
Токен бота хранится только в переменных окружения Vercel, не в HTML, не в GitHub и не в переписке.
Затем нужны серверная валидация, защита от спама, обработка ошибок, хранение заявок и проверка прав сотрудников.
Для реального сбора данных также необходимо оформить условия обработки персональных данных.

## Технически

HTML, CSS и JavaScript находятся в index.html. Изображение встроено.
Three.js загружается через CDN script tag. Если CDN недоступен, включается встроенная 3D-сцена на WebGL.
Если WebGL недоступен, остаётся статичная композиция. При prefers-reduced-motion движение отключено.

Это демо вымышленного бренда, не действующая клининговая компания.
