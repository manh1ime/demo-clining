# Сайт клининговой компании

Лендинг клининговой компании для Vercel. На нём есть калькулятор стоимости, интерактивная 3D-сцена и форма заявки. Заявки уходят менеджерам в Telegram, где у каждой есть кнопки статусов.

Сайт готов к запуску. Чтобы адаптировать его под компанию, замените заглушки в **одном файле — `config.js`**.

## 1. Данные компании: `config.js`

Значения в квадратных скобках `[...]`, нули и `example.com` — это заглушки. Замените их на реальные данные.

| Блок | Что указать | Где появится |
| --- | --- | --- |
| `brand.name` | Название компании | Заголовок вкладки, SEO, политика |
| `brand.logoText` | Текст логотипа | Шапка и подвал |
| `brand.bottleName`, `bottleLine1/2` | Надписи на 3D-флаконе | Первый экран |
| `city` | Город | SEO-описание, разметка для поисковиков |
| `site.url` | Домен сайта | Canonical, политика |
| `contacts.*` | Телефон, e-mail, адрес, часы работы, время ответа, мессенджеры | Шапка, блок заявки, подвал, политика |
| `legal.*` | Юр. название, ИНН, ОГРН, юр. адрес, e-mail для запросов по ПДн, дата политики | Подвал, политика конфиденциальности |
| `pricing.*` | Тарифы за м², минимальный заказ, доп. услуги | Калькулятор |

Ссылки на Telegram, WhatsApp и ВКонтакте с пустым значением на сайте не показываются.

### Что ещё заменить

- `robots.txt` и `sitemap.xml`: замените `https://example.com` на домен сайта.
- `favicon.svg`: иконка-заглушка. Её можно заменить логотипом компании в формате SVG.
- `privacy.html`: шаблон политики по 152-ФЗ, реквизиты подставляются из `config.js`. Перед запуском текст стоит показать юристу.
- Тексты страницы (заголовки, услуги, FAQ) находятся в `index.html`, если их нужно переписать.
- Фото в блоке «Дома можно просто быть» встроено в `index.html` (атрибут `src` у `<img>` в `.photo-section`). Его можно заменить на файл, например `/photo.jpg`.

## 2. Публикация на Vercel

1. Vercel → Add New → Project → импортируйте этот репозиторий.
2. Framework Preset: **Other**. Build Command оставьте пустым, Output Directory: `.`.
3. Нажмите Deploy.
4. Settings → Domains: подключите домен компании.

Сборка не нужна: сайт статический, серверные функции лежат в папке `api/`.

## 3. Заявки в Telegram

Форма отправляет заявку на `/api/lead`. Менеджер получает её в Telegram с кнопками статусов: 🆕 Новая → 🧹 В работе → 📞 Связались → ✅ Выполнена / ❌ Отменена.

1. В @BotFather создайте бота (`/newbot`) и скопируйте токен.
2. Создайте группу менеджеров и добавьте в неё бота. Можно и просто писать боту в личку.
3. Vercel → Storage: подключите **Upstash Redis** (подойдёт бесплатный тариф). Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` появятся сами.
4. Vercel → Settings → Environment Variables: добавьте переменные из `.env.example`:
   - `TELEGRAM_BOT_TOKEN` — токен бота;
   - `TELEGRAM_WEBHOOK_SECRET` — любая длинная строка из латиницы, цифр, `_` и `-`;
   - `TELEGRAM_CHAT_ID` — заполните после шага 6;
   - по желанию `LEAD_TITLE` (заголовок заявки в Telegram) и `DISPLAY_TZ` (часовой пояс, по умолчанию `Europe/Moscow`).
5. Сделайте Redeploy и откройте `https://ВАШ-ДОМЕН/api/setup?secret=ВАШ_СЕКРЕТ`. В ответ должно прийти `"ok": true`.
6. Напишите боту `/id`. Впишите полученный ID чата в `TELEGRAM_CHAT_ID` и снова сделайте Redeploy.
7. Отправьте с сайта тестовую заявку. Она придёт в чат с кнопками.

Команды бота: `/leads` — открытые заявки, `/lead 12` — заявка №12, `/id` — ID чата.

Без Redis бот тоже работает, но не будет сквозной нумерации, списка `/leads` и антиспам-лимита.

Токены храните только в переменных окружения Vercel, в коде их быть не должно.

## 4. Проверка после запуска

- Сайт открывается на компьютере и телефоне. 3D-сцена, кнопка паузы и появление блоков при прокрутке работают.
- Калькулятор: 50 м², поддерживающая уборка — 3 500 ₽. 80 м², генеральная уборка с окнами — 11 600 ₽ (при тарифах по умолчанию).
- Если телефон слишком короткий или нет согласия на обработку данных, форма не отправляется.
- Заявка приходит в Telegram, а на сайте появляется номер заявки.
- Страницы `/privacy.html` и любой несуществующий адрес (404) открываются.

## Структура

| Файл | Назначение |
| --- | --- |
| `config.js` | **Все данные компании и цены** |
| `index.html` | Главная страница: разметка, стили, калькулятор, 3D |
| `site.js` | Подставляет данные из `config.js` в страницы |
| `privacy.html` | Политика обработки персональных данных |
| `404.html` | Страница «не найдено» |
| `api/lead.js` | Приём заявки: проверка полей, honeypot, лимит 5 заявок за 10 минут с одного IP |
| `api/telegram.js` | Webhook бота: кнопки статусов и команды |
| `api/setup.js` | Регистрация webhook и меню команд |
| `api/_lib.js` | Общий код: Telegram API, Upstash Redis, форматирование |

Three.js подключается через CDN. Если CDN недоступен, работает встроенная сцена на WebGL. Если нет и WebGL, показывается статичная композиция. При `prefers-reduced-motion` анимации отключаются.
