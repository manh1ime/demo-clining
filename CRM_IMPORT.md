# Массовый импорт компаний

Войти в /admin, нажать «Импорт базы», выбрать подготовленный приватный JSON. Файл хранится у владельца, не в публичных файлах сайта.

До записи скачивается резервная копия; после — отчёт. Существующие карточки сопоставляются по источнику 2ГИС. Неоднозначные совпадения требуют ручной проверки. Статусы, история, заметки, тарифы и заполненные контакты не заменяются. Повтор одного файла не создаёт дублей по источнику. Параллельное изменение существующей карточки приводит к отказу импорта этой записи, а не к затиранию.

Фильтр группы не является статусом сделки. В карточке есть следующий шаг, предложение, черновик и отдельная кнопка 2ГИС. VK открывает vk.me, текст копируется. Telegram / WhatsApp по номеру не гарантируют существование аккаунта. Канал не считается личным чатом. Импорт ничего не отправляет компаниям.

Проверено локально: импорт 100 и повтор 100, сохранение статуса / заметок / тарифа, фильтр 12, кнопки 2ГИС / VK, защита входа, отсутствие приватного плана в публичном превью, ширины 390 / 320. Полный набор unit-тестов включает 13 тестов импорта. Живой импорт выполняется владельцем после входа.
