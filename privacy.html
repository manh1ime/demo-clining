Обработка данных

Политика конфиденциальности

Настоящая политика объясняет, какие данные получает сервис «Легче» при оформлении заявки и как они используются.

Какие данные собираются

При отправке формы пользователь может указать имя, телефон, желаемую дату, адрес или район, параметры уборки и комментарий.

Цель обработки

Данные используются только для расчёта, уточнения деталей заявки, согласования стоимости и связи с пользователем.

Передача данных

Сведения из заявки передаются менеджеру компании через защищённое сообщение в рабочем Telegram-чате. Данные не публикуются на сайте и не используются для автоматической рассылки.

Срок хранения

Данные хранятся не дольше, чем это требуется для обработки заявки и выполнения договорённостей, если более длительный срок не предусмотрен законом.

Права пользователя

Пользователь может запросить уточнение, исправление или удаление своих данных, обратившись к менеджеру тем же способом, которым велось общение по заявке.

Безопасность

  • токен Telegram-бота хранится только на сервере;
  • форма не передаёт данные сторонним рекламным сервисам;
  • доступ к рабочему чату ограничивается сотрудниками компании.

Согласие

Отправляя форму и устанавливая отметку согласия, пользователь подтверждает, что ознакомился с этой политикой и разрешает обработку указанных данных для связи по заявке.
