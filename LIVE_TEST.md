# Живой тест: настоящий сайт → настоящий Telegram

## Текущий статус

Код подготовлен в ветке feat/cleaning-demo-ready. Сохранение кода не равно публикации. На момент проверки 13.11.2026 опубликованный demo-clining.vercel.app показывал прежние заглушки. Из среды помощника прямое подключение к Vercel завершилось ошибкой DNS; настоящая заявка не отправлялась. Следующие шаги выполняются владельцем Vercel/Telegram совместно с помощником. Секреты в чат присылать не нужно.

## 1. Опубликовать обновлённую версию

В GitHub сравните main и feat/cleaning-demo-ready, проверьте изменения и объедините ветку через интерфейс GitHub. Ранее автоматическое создание PR было недоступно подключению. Дождитесь успешного Production Deployment в Vercel. Убедитесь, что домен https://demo-clining.vercel.app назначен именно ему.

Для закрытого теста НЕ переключайте site.demo в false. Публичный пример должен оставаться безопасным.

## 2. Настроить инфраструктуру в Vercel

Settings → Environment Variables → Production:

- TELEGRAM_BOT_TOKEN — существующий токен BotFather.
- TELEGRAM_CHAT_ID — ID вашего личного чата с ботом или закрытой группы менеджеров.
- TELEGRAM_WEBHOOK_SECRET — случайная длинная строка из латинских букв, цифр, _ и -; от 32 символов, не пароль от аккаунта.
- KV_REST_API_URL и KV_REST_API_TOKEN — данные подключённого Redis; поддерживаются также UPSTASH_REDIS_REST_URL/UPSTASH_REDIS_REST_TOKEN.
- ADMIN_PASSWORD — длинный уникальный пароль вашей CRM.
- PUBLIC_SITE_URL=https://demo-clining.vercel.app
- LIVE_TEST_MODE=true — временно для проверки.
- TELEGRAM_MANAGER_IDS — рекомендуется: ваш числовой Telegram ID. Несколько ID через запятую.
- DISPLAY_TZ=Europe/Moscow

После изменения переменных выполните Redeploy. Не добавляйте реальные .env-файлы в GitHub.

## 3. Подключить Telegram

Откройте своего бота в Telegram и нажмите Start. Для группы добавьте его в закрытую группу; команды можно адресовать как /id@имя_бота. ID группы отличается от личного ID. Если ID ещё неизвестен, сначала выполните подключение webhook следующей командой (это возможно без CHAT_ID), затем отправьте /id боту. Перенесите возвращённый ID чата в TELEGRAM_CHAT_ID, свой ID в TELEGRAM_MANAGER_IDS и сделайте Redeploy; после этого запустите проверку готовности. Токен сторонним ботам не передавайте.

На своём компьютере в папке проекта создайте .env.setup:

```
PUBLIC_SITE_URL=https://demo-clining.vercel.app
TELEGRAM_WEBHOOK_SECRET=ваш_секрет_из_Vercel
```

Запустите с Node.js, поддерживающим --env-file:

```
node --env-file=.env.setup scripts/setup-telegram.mjs
node --env-file=.env.setup scripts/check-live.mjs
```

Первая команда подключает webhook и меню команд; не удаляет накопленные обновления Telegram. Вторая только проверяет подключение, не создаёт заявку. Она использует закрытую проверку на сайте, выводит только безопасные признаки готовности и имя бота, без токена и пароля.

Ожидаются database=true, managerChat=true, webhookMatches=true, liveTestEnabled=true, adminEnabled=true. Наличие этих признаков не доказывает прохождение заказа: нужен следующий шаг. webhookHasError может отражать последнюю ошибку доставки — проверьте актуальность после теста.

Напишите /id и /help боту. Убедитесь, что это нужный чат, пользователь имеет доступ, а команды соответствуют новой версии. Пока /help не отвечает — не отправляйте заказ.

## 4. Отправить заявку именно с опубликованного сайта

1. В том же браузере войдите в https://demo-clining.vercel.app/admin своим ADMIN_PASSWORD.
2. Откройте https://demo-clining.vercel.app/?live-test=1
3. Должно появиться предупреждение «ЖИВОЙ ТЕСТ» и кнопка «Отправить тест в Telegram». Если этого нет, версия ещё не обновлена.
4. Выберите генеральную уборку, 80 м², окна. Ожидаемый расчёт учебного бренда: 11 600 ₽.
5. Имя: «ТЕСТ — не звонить». Телефон: +7 (000) 000-00-00. Не используйте случайный настоящий номер. Дата: завтра. Комментарий: «Проверка сайта и бота, не настоящий заказ». Подтвердите тестовое согласие.
6. Нажмите отправку ОДИН раз. Запишите номер заявки и ответ страницы.
7. В настоящем Telegram должна прийти карточка с тем же номером, параметрами, суммой и меткой «ЖИВОЙ ТЕСТ — не настоящий заказ».

Если ответ 403 — проверьте вход в /admin в этом же браузере и LIVE_TEST_MODE. Если 429 — подождите ограничение. Если ошибка Telegram — сначала выполните /leads: запись уже могла сохраниться; не отправляйте форму многократно. Не отправляйте скриншоты с настоящими персональными данными или секретами.

## 5. Пройти работу менеджера

Вместо N используйте полученный номер:

1. «Взять в работу». Должен появиться ваш ответственный.
2. /mine — заявка должна быть в списке.
3. «Связались». В реальной работе это отметка после звонка, в тесте никому звонить не нужно.
4. /note N Учебный адрес, проверка сценария.
5. /price N 11600 — согласованная цена должна появиться отдельно от предварительной.
6. /schedule N ГГГГ-ММ-ДД 10:00 — подставьте завтрашнюю дату. Статус «Согласована».
7. «Выполнена» — сначала отдельный вопрос. До подтверждения заказ остаётся открытым.
8. Подтвердите выполнение. /leads и /mine больше не должны показывать этот заказ, /lead N должен открывать завершённую карточку с историей.
9. Для проверки отмены верните тест в работу, отправьте /cancel N Учебная отмена, подтвердите и проверьте причину.
10. Повтор старого подтверждения после изменения карточки не должен менять актуальное состояние.

## 6. Зафиксировать реальный результат

Сообщите помощнику публичное @имя бота (не токен), номер тестовой заявки, текст ответа сайта и результаты кнопок. Скриншот карточки — только с тестовыми данными. Без этих наблюдений полный цикл НЕ считается подтверждённым.

После проверки установите LIVE_TEST_MODE=false и сделайте Redeploy. Не переводите учебный бренд в рабочий приём заказов. Историю теста при необходимости можно оставить как помеченную тестовую запись; отдельной кнопки удаления заявок сейчас нет.

## Границы проверки

Локальные автоматические тесты используют имитации Telegram и Redis. Имя бота и действующие серверные секреты помощнику неизвестны. Со стороны помощника нет доступа к аккаунту Telegram пользователя и панели Vercel. Никаких утверждений об успешной реальной доставке до выполнения шагов выше нет.
