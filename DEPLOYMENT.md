# Подготовка публичного сайта к Vercel

Публикация не выполнялась. В production-сборку входят клиентский сайт и защищённый экран CRM. Резервные копии и база лидов в `dist` не попадают.

## Переменные окружения

Добавьте в настройках проекта Vercel:

- `TELEGRAM_BOT_TOKEN` - токен существующего Telegram-бота.
- `TELEGRAM_CHAT_ID` - идентификатор личного чата или группы, куда должны приходить заявки.
- `TELEGRAM_THREAD_ID` - необязательный идентификатор темы внутри группы.
- `TELEGRAM_WEBHOOK_SECRET` - длинная случайная строка для проверки входящих команд Telegram.
- `PUBLIC_SITE_URL` - production-адрес Vercel, например `https://project.vercel.app`.
- `ADMIN_PASSWORD` - пароль входа во внутреннюю панель лидов.
- `ADMIN_SESSION_SECRET` - необязательный отдельный ключ подписи сессии. Если не указан, используется `ADMIN_PASSWORD`.

Токен нельзя добавлять в HTML, JavaScript браузера, Git или URL.

После первого deploy настройте команды бота локально, передав секреты только через переменные процесса:

```powershell
$env:PUBLIC_SITE_URL="https://project.vercel.app"
$env:TELEGRAM_WEBHOOK_SECRET="тот-же-секрет-что-в-vercel"
npm run telegram:setup
```

После этого бот отвечает на `/start`, `/id`, `/test` и `/help` в личных чатах и группах.

## Локальная проверка

```powershell
npm install
npm run dev
npm run build
npm run build:local
```

`npm run dev` не отправляет сообщение в Telegram, но проверяет полный клиентский сценарий. Для проверки самой serverless-функции с переменными окружения используйте `vercel dev` только локально.

## Перед реальной публикацией

1. Подставить реальные реквизиты компании и политику обработки персональных данных.
2. Проверить `TELEGRAM_CHAT_ID` тестовой заявкой.
3. Ограничить доступ к Telegram-группе сотрудниками компании.
4. При большом рекламном трафике подключить постоянный rate limit для `/api/lead`.
5. Проверить домен, аналитику и юридические тексты отдельно.
6. Открыть `/leads.html`, проверить пароль и импортировать локальный JSON через безопасный предпросмотр. JSON с контактами не загружается из Git автоматически.
